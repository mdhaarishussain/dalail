# apps/mobile

Expo (custom dev client) + Expo Router. Lite mode: on-device search with FTS5 + e5 embeddings.
Routes live in `src/app/`, screens in `src/screens/`, UI strings in `src/i18n/`.

## Run on an Android emulator or phone

```bash
# 1. Build the corpus DB the app bundles (dev build: fixtures + drafts, with embeddings)
cd pipeline && uv sync --extra embed && uv run python -m dalail_pipeline fetch-model
uv run python -m dalail_pipeline build --dev
cd ..
# 2. Build and install the dev client (needs the Android SDK; first build takes a while)
pnpm --filter @dalail/mobile android
```

For a prod-variant build: `build --prod --out ../dist/prod`, then `APP_VARIANT=prod` for prebuild.

## Tests

```bash
cd pipeline && uv run python -m dalail_pipeline build --dev --no-embed --out ../dist/ci && cd ..
pnpm --filter @dalail/mobile test
```

Native folders (`android/`, `ios/`) are generated by `expo prebuild` and not committed.
See `docs/decisions/0005-app-data-and-assets.md` and `0006-fonts.md`.
