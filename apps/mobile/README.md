# apps/mobile

Expo (custom dev client) + Expo Router app. Routes live in `src/app/`; UI strings in `src/i18n/`.

```bash
pnpm --filter @dalail/mobile android   # build & run dev client on emulator/device (needs Android SDK)
pnpm --filter @dalail/mobile start     # Metro for an installed dev client
pnpm --filter @dalail/mobile test
```

Native folders (`android/`, `ios/`) are generated by `expo prebuild` and not committed.
